# 🛒 Flask E-Commerce API
*Backend Developer | Python Flask SQL | UOM | Islamabad*

Scalable E-Commerce Backend built with Flask + SQLAlchemy + SQLite/PostgreSQL.

### 🚀 Features
- RESTful APIs: GET /api/products, POST /api/products
- SQLAlchemy ORM: Product Model with CRUD & Transactions
- Ready to extend: Users, Orders, JWT Auth, ACID Compliance

### 🛠️ Tech Stack
Python, Flask, Flask-SQLAlchemy, SQLite, REST APIs, GitHub

### ▶️ How to Run Locally
```bash
pip install -r requirements.txt
python app.py
# Server runs at http://127.0.0.1:5000
