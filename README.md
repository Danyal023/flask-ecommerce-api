# Flask E-Commerce API - Full Stack Backend

Live API with Database - Like Daraz/Amazon Backend

## Features
- FULL CRUD: GET, POST, PUT, DELETE
- Database: SQLite with SQLAlchemy - Data saves forever
- RESTful API: Professional JSON responses
- E-Commerce Ready: Products with price, category

## Tech Stack
Python, Flask, SQLAlchemy, SQLite, REST APIs, Git

## API Endpoints
- GET /products - List all products
- GET /products/<id> - Get single product
- POST /products - Add new product
- PUT /products/<id> - Update product
- DELETE /products/<id> - Delete product

## Run Locally
pip install flask flask_sqlalchemy requests
python app.py
Open http://127.0.0.1:5000/products
